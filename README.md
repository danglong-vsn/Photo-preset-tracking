# Photo Preset Tracking (photo-look-to-xmp)

Công cụ phân tích thông số màu sắc từ hình ảnh và tự động xuất ra file Preset XMP dành cho Lightroom / Photoshop.

---

## 🌟 Tính năng chính

- **Phân tích màu sắc (Color Analysis):** Tự động đọc và trích xuất tone màu, tương phản từ ảnh mẫu.
- **Tạo file XMP:** Xuất kết quả phân tích thành định dạng `.xmp` tương thích với Lightroom và Adobe Camera Raw.
- **Hỗ trợ 2 giao diện:**
  - **Giao diện đồ họa (GUI):** Dễ sử dụng, kéo thả hình ảnh trực quan.
  - **Dòng lệnh (CLI):** Nhanh chóng, phù hợp để xử lý hàng loạt.
- **Đóng gói đa nền tảng:** Có sẵn script đóng gói ứng dụng cho cả Windows và macOS.
